# 永续合约结算说明（交易者版）

> 读完应能回答：  
> 1）平仓时钱从哪来？  
> 2）和币安等所的「保险基金 + ADL」是不是一类？  
> 3）什么情况下可能被自动减仓？  
> 4）链上公开相对中心化所多了什么？

---

## 1. 一句话

本协议永续：

- **链下撮合、链上结算**
- 每个市场有一个链上 **系统账户**（作用类似 CEX **保险基金**，并可在强平时 **接仓**）
- 流程与传统所同构：

```text
强平 → 剩余保证金进入系统账户，仓位由系统接走
     → 系统账户健康则正常兑付赢家
     → 系统账户触及危险线 → 对赢方 ADL（自动减仓/强制结算）
```

**不做「欠条 Claim」**：不会给你一张「以后再付款」的凭证；缓冲不够时，用 **ADL** 强制减掉部分赢方仓位，把系统拉回安全区——与主流交易所尾部手段同类。

---

## 2. 钱在哪

入金后，保证金在 **Perps 金库**（与 Spot 金库分开）。  
盈亏来自对手盘；强平后无人接的仓，由 **系统账户** 临时持有。

永续绕不开的事实（CEX 也一样）：

> 强平往往只能清掉亏方，不能同时强平所有赢方；  
> 系统账户用清算注入的资金和接仓来扛中间这段；  
> 扛不住时，就对赢方自动减仓。

---

## 3. 系统账户（≈ 保险基金，链上可见）

### 3.1 钱从哪来（与 CEX 保险基金同类）

| 来源 | 说明 |
|------|------|
| 强平剩余保证金 | 被强平用户剩下的保证金进入系统账户 |
| 清算罚金 | 若收取，进入系统账户 |
| 亏损平仓贡献 | 按规则可进入 |
| 手续费 / 资金费分成 | 可配置 |
| 协议注资 | 若发生，链上可查 |

### 3.2 仓从哪来

用户被强平时：

1. 其剩余保证金进入该市场 **系统账户现金**  
2. 其仓位 **改挂到系统账户**（系统接仓）  
3. 之后系统可在市场上平掉这些仓；盈亏计入系统账户

### 3.3 你怎么用这个信息

关注展示中的 **系统账户权益**，以及运营设定的 **ADL 权益阈值**（固定金额）：

- 权益远高于阈值：缓冲健康  
- 权益降到阈值附近或以下：进入 ADL 区  

ADL 触发：**当前权益 ≤ 合约内固定阈值**（该阈值由运营按当时总金额约 8% 设入；合约不动态算百分比）。

---

## 4. 平仓时你可能遇到的结果

### 结果 A：正常足额结算

系统账户健康 → 按成交规则结算盈亏，体验与常规交易所同类。

### 结果 B：系统账户触线 → ADL

当系统账户权益低至阈值：

- 协议可能对 **盈利且风险贡献高** 的仓位 **自动减仓或强制结算**  
- 目的是降低系统敞口、恢复缓冲  
- **这与 CEX 保险基金耗尽后的 ADL 同类**  
- 没有 Claim：不是「少付一点以后再给」，而是 **仓位被减掉**

---

## 5. 和 CEX 保险基金怎么比

| | 典型 CEX | 本协议 |
|--|----------|--------|
| 缓冲账户 | 保险基金 | **系统账户**（链上） |
| 强平后谁接仓 | 清算人 / 内部账户等 | **系统账户接仓**（v0） |
| 缓冲不够 | ADL | **ADL** |
| 欠条 | 通常无公开 Claim | **无 Claim** |
| 你多看到的 | 基金规模有时可见 | **余额、接仓、规则可核验** |

> 经济流程对齐传统所；  
> 差异主要在 **透明与链上可验证**，不是「另一套更刚兑的数学」。

---

## 6. 风险清单（务实）

1. **行情与杠杆风险**：亏到强平  
2. **系统账户压力**：单边行情后缓冲变薄  
3. **ADL 风险**：极端情况下盈利仓被自动减掉  
4. **再平衡风控**：限仓、保证金、资金费调整  

普通无法消除：预言机剧烈波动、链上拥堵等。

**自保：** 看系统账户健康度；极端行情降低对「一定拿满所有浮盈」的预期；控制杠杆。

---

## 7. 极简故事

1. A 做多、B 做空，价格大涨，B 被强平。  
2. B 的剩余保证金进入系统账户；B 的空仓改挂到系统。  
3. 价格继续涨，系统账户接仓亏损，权益下降。  
4. 若权益仍健康：A 平仓按规则正常结算。  
5. 若权益触线：对包括 A 在内的高盈利仓启动 **ADL**，强制减仓，修复系统账户。

这不是「链上独有的坑」，而是 **有限缓冲永续** 的标准尾部路径；本协议把它放在链上说清楚。

## 9. 术语

| 术语 | 人话 |
|------|------|
| 系统账户 | 每市场的协议账户：现金缓冲 + 可接强平仓；≈ 保险基金 |
| 强平 | 保证金不足，仓位被强制处理 |
| 接仓 | 强平后仓位挂到系统账户 |
| ADL | 自动减仓：强制减少赢方仓位以保护系统 |
| 保险基金 | CEX 同类缓冲；本协议用链上系统账户承接 |

差别是系统账户在链上，规则事先写清，状态你可以核对。**
