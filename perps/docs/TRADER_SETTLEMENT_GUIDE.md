## 1. 一句话

本协议是 **ERCS20 标的永续合约**：

- **链下撮合、链上结算**（仓位与保证金规则在链上可核验）
- 强平仓位由协议批准的 **清算人账户（L）** 接走（作用类似 CEX 保险基金账户，可持仓）
- L 保证金触线时，对用户盈利仓执行 **ADL（自动减仓）**
- **不做 Claim（欠条）**：缓冲不够时减仓，而不是开一张「以后再付」的凭证

```text
强平 → 仓位与正保证金并入清算人 L（可同时追保）
     → L 可在市场上正常减仓
     → L 保证金 ≤ 阈值 → 对赢方 ADL（与 L 强制对敲）
```

## 2. 账户与价格（必须分清）

### 2.1 钱在哪

| 位置 | 含义 |
|------|------|
| **Perps 金库** | 你的可用保证金（原生 USDC，与 Spot 金库分开） |
| **市场 Balance** | 该市场锁定的保证金 `margin` + 仓位 `position`（有符号） |

开仓时按订单锁定保证金；平仓后剩余可退回金库。  
盈亏在对手盘成交时按 **成交价** 计入双方账户。

### 2.2 三种价格

| 名称 | 是什么 | 主要用途 |
|------|--------|----------|
| **最新成交价 Last** | 最近一笔链上结算成交价 | K 线 / 成交展示；**已实现盈亏**按你的成交价结算 |
| **标记价格 Mark** | ERCS20 现货中间价的 **15 分钟 TWAP**（运营/成交路径采样） | **强平判定**、ADL、未实现盈亏展示、资金费 Index 计价 |
| **现货价 Spot** | 对应 ERCS20 池储备价（`getReserves`） | **资金费**升贴水计算的一侧；也是 Mark 的采样源 |

**Mark 怎么更新（当前规则）：**

- 采样触发：链上成交结算，或运营调用更新入口（均需运营权限）  
- 最短采样间隔：**30 秒**  
- 窗口：**过去 15 分钟** 的时间加权平均（TWAP）  
- 两次采样之间，按「价格等于上一次采样」推进平均  

**重要：**

- 平常开平仓的真实划转看 **成交价（Last 体系）**，不是 Mark。  
- **会不会被强平**看 **Mark**（及维持保证金规则），不是 Last。  
- 资金费升贴水看 **Last 相对 Spot**；支付进保证金时还会用 Mark 参与 Index 换算（见第 5 节）。

## 3. 清算人账户 L（≈ 保险基金，链上可见）

### 3.1 角色

每个市场共用协议配置的清算人地址（可为多签）。强平后：

1. 你的仓位并入该清算人在该市场的 Balance  
2. 你账户上 **正的** 保证金并入清算人；**负保证金不注入**（视为已穿仓部分）  
3. 运营可在强平时为清算人 **追加保证金（marginTopUp）**，降低立刻触发 ADL 的概率  
4. 清算人之后可像普通账户一样通过成交减仓

清算人 **不能被再次强平**；压力过大时走 **ADL**。

### 3.2 ADL 何时触发

合约比较的是清算人在该市场的 **保证金 margin**（不是复杂权益公式）：

```text
清算人 margin ≤ 该市场设定的 ADL 阈值  →  可执行 ADL
```

阈值由运营写入链上（绝对金额）。触线后，协议可将你的仓位与清算人仓位按 **Mark** 强制对敲减仓。

ADL 与币安等所「保险基金压力过大 → 自动减仓」同类：**没有 Claim，仓位被减掉。**

## 4. 平仓 / 强平你可能遇到的结果

| 情形 | 结果 |
|------|------|
| 正常对手盘成交 | 按成交价结算，体验与常规交易所同类 |
| 你被强平 | 仓位进清算人；正保证金被接管 |
| 清算人触线 ADL | 你的盈利仓可能被强制减仓（按规则选对手） |

## 5. 资金费（Funding）——请重点阅读

资金费用于把 **永续价格** 拉向 **现货价格**：升水时多头付给空头，贴水时空头付给多头。  
支付在持仓用户之间进行，**协议不从资金费抽成**（当前实现）。

### 5.1 怎么算（当前链上规则）

每隔至少 **5 分钟**（由运营通过成交或专用入口采样一次）：

```text
现货 Spot  = ERCS20 储备中间价
升贴水 P   = (最新成交价 Last − Spot) / Spot
8 小时费率 = 将 P 限制在 ±0.75% 以内
每秒费率   = |8 小时费率| / 8 小时
```

之后按你持仓时间 **懒结算**进保证金（开仓、加仓、资金费结算、强平等路径都可能触发结算）。

| 参数 | 数值 |
|------|------|
| 采样最短间隔 | **5 分钟** |
| 费率上限（8 小时口径） | **±0.75%** |
| 约合简单年化上限 | 约 **821%**（若长期顶格，极少见） |
| 固定利息项（Interest） | **当前为 0**（未加币安式 0.01%/8h） |

### 5.2 和你的关系

- 持仓越久、费率越大（且方向对你不利），保证金被扣得越多。  
- 费率由 **Last 与现货的偏离** 驱动；偏离被夹在 ±0.75%/8h。  
- 采样由运营侧触发；长时间无采样时，沿用 **上一笔已缓存费率** 继续按时间累积。

### 5.3 你需要同意的表述

> 我理解资金费按「永续最新成交价相对 ERCS20 现货」的升贴水计算，  
> 上限为每 8 小时 ±0.75%，至少每 5 分钟可更新一次采样，  
> 并以懒结算方式计入我的保证金；极端升贴水时资金费成本可能很高。

## 6. 和中心化交易所怎么比

| | 典型 CEX | 本协议 |
|--|----------|--------|
| 撮合 | 中心化 | 链下撮合 |
| 仓位 / 规则 | 黑箱或半公开 | **链上可核验** |
| 缓冲 + 接仓 | 保险基金 / 内部户 | **清算人账户 L** |
| 不够时 | ADL | **ADL** |
| 欠条 Claim | 通常无 | **无** |
| 资金费 | 多所指数 + 复杂 Premium | **Last vs 本协议 ERCS20 现货**，±0.75%/8h |
| 强平价 | Mark | **Mark（预言机）** |

经济流程与交易所同构；差异主要在 **透明与链上可验证**，以及现货指数来源（本协议现货池）。

## 7. 风险清单（务实）

1. **行情与杠杆**：亏损可至强平，本金可全部损失。  
2. **清算人压力**：单边行情后 L 缓冲变薄。  
3. **ADL**：极端情况下盈利仓被自动减掉。  
4. **资金费**：长期单边升贴水时持仓成本可显著上升（有 0.75%/8h 上限）。  
5. **价格源**：Mark / 现货 / Last 不一致时，强平与资金费可能与你对「盘面价」的直觉不同。  
6. **运营与技术**：撮合运营、暂停、预言机、链上拥堵、合约升级 / 治理风险。  
7. **无无限刚兑**：协议不承诺「浮盈一定能全部兑付」。

**自保建议：** 控制杠杆；关注清算人健康度与 ADL 阈值；理解资金费方向；极端行情降低「一定拿满所有浮盈」的预期。

## 8. 极简故事

1. A 做多、B 做空，价格不利 B，B 被强平。  
2. B 的仓位与正保证金进入清算人 L。  
3. 若价格继续对 L 持仓不利，L 的保证金下降。  
4. L 保证金仍高于阈值：市场正常成交、正常结算。  
5. L 保证金触线：对包括 A 在内的高盈利仓 **ADL**，与 L 强制减仓。  

这是有限缓冲永续的标准尾部路径；本协议把它写在链上并事先告知。

## 10. 术语

| 术语 | 含义 |
|------|------|
| Last | 最新成交价 |
| Mark | 标记价格（风控 / 强平） |
| Spot | ERCS20 现货中间价 |
| 清算人 L | 接强平仓的协议侧账户，≈ 保险基金账户 |
| 强平 | 保证金不足，仓位被强制移交清算人 |
| ADL | 自动减仓：强制减少赢方仓位以保护清算人 / 系统 |
| 资金费 Funding | 多空之间按升贴水定期结算的费用 |
| Claim | 欠条式延期兑付（本协议不做） |
